Ray-sets are polyhedra

Give every ray a face tangent to the sphere — keep only what lies inside all of them, { x : r·x ≤ 1 } — and each ray-set becomes a solid. One face per ray, so turning a face is turning about a ray. O·6 is a cube, O·8 an octahedron, I·12 a dodecahedron (the Megaminx).

The shell is cosmetic. What defines the puzzle is the ray-set, not the outer shape. A tetrahedron-shaped 3×3×3 (the Mastermorphix) has the same rays as a Rubik's Cube — same axis system, different shell. These solids are just the most natural body for each ray-set.
