# The 16 ray-sets (tutorial stop #3)

An interactive three.js browser for the headline result: the **16** twisty-puzzle axis
systems with polyhedral symmetry. Each is a bundle of rays from the centre — the
directions you can turn around — drawn as arrows and coloured by family.

## Run it
Open **`ray-set-explorer.html`** in a browser. Fully self-contained — three.js r128 and
OrbitControls are vendored here, so it runs offline.

- **Ray-set** dropdown — the 16, grouped by symmetry (T / O / I).
- **Spin about** any ray (pick from the dropdown, or **click a ray** in the view): the
  whole bundle turns around it and lands **exactly back on itself** — the closure
  property that makes these bundles valid. Ghost dots mark the rest positions; a banner
  confirms when it realigns.
- **keep spinning** loops the rotation; a **sphere opacity** slider fades the reference
  ball.

The white ray is the current spin axis (it sits still); the rest are coloured by
**family** — the rays the symmetry group shuffles among themselves.

## Why it's stop #3
This is the payoff of `1_ray_sets/`: a complete, finite list exists. It shows the **16**
distinct ray-sets (from `systems_data.js`), not the 21 pre-dedup candidates the
matplotlib `rayview` viewer steps through.
